# 安全重构（中文）

## 目标
在不改变外部行为的前提下，降低复杂度并提升可维护性。

## 重构原则
- 小步快跑：每次改动可独立验证。
- 行为等价：重构前后输入输出一致。
- 先保护后重构：必要时先补测试。

## 常用动作
1. 提取长函数为小函数。
2. 消除重复逻辑，收敛公共实现。
3. 明确模块边界，减少跨层耦合。
4. 统一命名和错误处理方式。

## 验证要求
- 至少执行一条与改动相关的测试或运行命令。
- 说明“为何此改动不改变行为”。

## 输出格式
1. 重构目标
2. 关键改动
3. 行为等价说明
4. 验证结果
5. 后续可继续重构点
