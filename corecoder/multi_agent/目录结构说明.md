# multi_agent 目录结构说明

本目录聚焦多智能体编排，负责 Supervisor、动态执行草案、专家任务实现。

## 文件说明

- `__init__.py`：`SuperAssistant` 主编排骨架与对外入口。
- `plan_engine.py`：动态编排引擎（planner + action 执行器注册表、确认闸）。
- `session_context.py`：SuperAssistant 会话上下文与快照持久化。
- `multi_agent_mail.py`：邮件专家任务 mixin（读信、搜索、概括、发信确认等）。
- `multi_agent_file.py`：文件专家任务 mixin（读写、搜索、格式转换）。
- `multi_agent_browser.py`：浏览器专家任务 mixin（历史检索、导出、统计）。

## 设计要点

- 采用 mixin 组合，减少单文件复杂度。
- 动态编排支持“先出草案，再确认执行”。
- 通过 `/debug` 可查看已注册 planners/actions。
