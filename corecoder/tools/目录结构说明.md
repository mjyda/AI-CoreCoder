# tools 目录结构说明

本目录是 CoreCoder 可调用工具集合，按“一个工具一个文件”组织。

## 通用基础

- `base.py`：工具基类与 schema 约定。
- `__init__.py`：工具注册总入口（`ALL_TOOLS`）。
- `sandbox.py`：文件沙箱约束与路径校验。

## 主要工具类别

- 文件类：`read.py`、`write.py`、`append.py`、`edit.py`、`list_directory.py`、`file_info.py`、`search_files.py`、`grep_in_files.py`
- 终端类：`bash.py`
- 代码检索类：`glob_tool.py`、`grep.py`
- 浏览器类：`browser_history.py`
- 邮件类：`mail_imap.py`
- 代理工具：`agent.py`

## 维护建议

- 新增工具时保持独立文件，补齐 `name/description/parameters/execute`。
- 在 `__init__.py` 注册后才能被系统发现与调用。
