# runtime 目录结构说明

本目录是 CoreCoder 的基础运行时实现，不绑定具体业务专家。

## 文件说明

- `agent.py`：Agent 主循环（LLM 对话、工具调用、并行执行）。
- `llm.py`：OpenAI 兼容模型包装层（流式、工具调用解析、费用统计）。
- `prompt.py`：系统提示词模板生成。
- `context.py`：上下文压缩策略（snip / summarize / collapse）。
- `session.py`：会话保存、读取、列表管理。
- `skills.py`：Skill 发现、加载、拼接提示词。
- `__init__.py`：runtime 层统一导出。

## 适用场景

当你需要改“底层行为”（如工具调用协议、上下文压缩策略、会话机制）时，优先在本目录修改。
