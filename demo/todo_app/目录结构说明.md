# demo/todo_app 目录结构说明

本目录是 Todo 示例应用代码，用于演示基础业务分层和测试方式。

## 主要文件

- `main.py`：示例入口。
- `todo.py`：Todo 核心实体/逻辑。
- `storage.py`：数据存储相关实现。
- `todo_service.py`：服务层封装。
- `todo_api.py`：接口层示例。
- `test_todo.py`、`simple_test.py`、`stress_test.py`：测试/压力测试脚本。
- `test.json`：示例数据文件。

## 适用用途

- 快速验证 Agent 对项目代码的理解与改动能力。
- 作为编写新工具或新流程时的轻量演示项目。
